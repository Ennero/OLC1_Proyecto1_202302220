## 📌 Descripción General

Este repositorio contiene la implementación y entrega de **📑 Lexical and Syntactic Compiler Analyzer in Java (OLC1)**, desarrollado en el curso de **Organización de Lenguajes y Compiladores 1** en la Universidad de San Carlos de Guatemala.

- **Objetivo:** Analizador léxico y sintáctico con generación de árboles de derivación y tablas de símbolos en Java.
- **Stack Principal:** `Java`.
- **Área:** Ciencias de la Computación, Algoritmos y Desarrollo de Software.
